# Портативная установка (на станцию без Python)

Модулятор подключён по COM, поэтому приложение должно работать **на самой станции**.
Чтобы не ставить туда Python, кладём портативный Python прямо в папку приложения.
Всё, что требует интернета и Python, делается **один раз на ноутбуке**, а на станцию
копируется готовая папка.

---

## Часть A — на ноутбуке (где есть Python и интернет)

**Шаг 1. Узнать версию своего Python.**
В командной строке:
```
python --version
```
Запомни версию (например, 3.11.x).

**Шаг 2. Скачать портативный Python.**
Открой https://www.python.org/downloads/windows/ и найди
**«Windows embeddable package (64-bit)»** той же версии X.Y, что и в шаге 1
(например 3.11). Это zip примерно на 10 МБ.

**Шаг 3. Распаковать его в папку `python`.**
Внутри папки приложения (там, где лежит `app.py`) уже есть подпапка `python` с файлом
`READ_ME_FIRST.txt`. Распакуй туда содержимое скачанного zip так, чтобы получилось:
```
rf_verification_app\python\python.exe
rf_verification_app\python\python3XX.zip
rf_verification_app\python\python3XX._pth
```

**Шаг 4. Запустить сборку.**
Дважды кликни **`build_portable.bat`**. Он:
- поставит Flask и pyserial в папку `libs\`;
- настроит портативный Python, чтобы он видел приложение и `libs`.
В конце появится «DONE».

**Шаг 5. Скопировать всю папку на станцию.**
Скопируй целиком папку `rf_verification_app` (уже с `python\` и `libs\`) на COM-станцию —
на флешке или по сети. На станции Python ставить **не нужно**.

---

## Часть B — на станции (без Python)

**Шаг 6. Запуск.**
Дважды кликни **`run.bat`**. Откроется браузер на `http://127.0.0.1:5000`.
Окно консоли держи открытым, пока работаешь; закрыть окно (или Ctrl+C) — остановить.

**Шаг 7. Настройки перед первым прогоном.**
Вкладка **Settings**: поставь `dut_conn_type = serial`, укажи `dut_com_port`
(например `COM168`) и `dut_baud = 115200`; проверь `cxa_ip = 192.168.0.5` и
`ext_gain_db = -3.50`. Нажми **Save configuration**.

Дальше — вкладка **Run**.

---

## Если что-то не так

| Симптом | Решение |
|---------|---------|
| `run.bat`: «Portable Python not found» | Папку не собрали. Вернись к части A (шаги 3–4). |
| Ошибка про `vcruntime140.dll` при старте | Установи на станции «Microsoft Visual C++ Redistributable (x64)». На Windows 10/11 обычно уже есть. |
| `build_portable.bat`: «pip install failed» | Нет интернета на ноутбуке — проверь соединение и запусти снова. |
| Импорт flask падает на станции | Версия embeddable Python не совпала с версией Python на ноутбуке. Пересобери с embeddable той же X.Y. |
| «Cannot open COMxx» | Порт занят Tera Term / PuTTY — закрой их. Или неверный номер порта в Settings. |

> Важно: и ноутбук, и станция должны быть **64-битными Windows**. Пакет собирается под
> x64; переносить на 32-битную систему нельзя.
